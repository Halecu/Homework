Exercise 1: Welford’s Recurrence Formulas

Welford’s algorithm calculates running means and sums of squares ($SS$) in a single pass ($O(1)$ memory per step) without storing the entire dataset. This prevents numerical instability (catastrophic cancellation) caused by standard two-pass formulas.

Mathematical Recurrence

  • Mean Update:
    $\delta_n = x_n - M_{n-1}$
    $M_n = M_{n-1} + \frac{\delta_n}{n}$
  • Sum of Squares ($M_2$) Update:
    $S_n = S_{n-1} + \delta_n(x_n - M_n)$
  • Sample Variance: $s^2 = \frac{S_n}{n-1}$

// Welford Core Logic (3 Lines)

let n = 0, mean = 0, M2 = 0;

for (let x of dataset) {

n++;

let delta = x - mean;

mean += delta / n;

M2 += delta * (x - mean);

}

// Variance = M2 / (n - 1)

Conclusions & Inferential Statistics Insights

1. Unbiased Estimation: Across all tested values of $n$, the average of the sampling means converges precisely to the theoretical mean $\mu = 5.0$, and the average of sampling variances converges to $\sigma^2 = 10.0$, confirming that sample statistics are unbiased estimators.

2. Effect of Increasing $n$: As the number of systems attempted ($n$) increases, the variance of the sample means ($\text{Var}(\bar{x}) = \frac{\sigma^2}{n}$) decreases significantly. This validates the **Law of Large Numbers** and the **Central Limit Theorem**, demonstrating that larger sample sizes provide much higher estimation precision and stability.

3. Usefulness in Practice: In real-world cybersecurity auditing and threat intelligence, analysts rarely observe the entire population of potential system vulnerabilities. Using robust single-pass estimators like Welford's algorithm allows efficient computation of sample parameters with high precision.
