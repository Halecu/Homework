1. Elliptic Curve Cryptography (secp256k1 Toy Scheme)

The secp256k1 curve is defined over a prime field by the short Weierstrass equation:

y^2 = x^3 + 7 (mod p)

In a toy implementation of an asymmetric EC-based encryption scheme (modeled after Elliptic Curve ElGamal / ECIES), messages are mapped to points on the curve, and security relies on the hardness of the Elliptic Curve Discrete Logarithm Problem (ECDLP).

Main Algorithm Steps

  1. Key Generation: Choose a private key $d$ randomly from $[1, n-1]$ (where $n$ is the base point order). Compute public key $Q = dG$ via scalar multiplication.
  2. Encryption: Encode plaintext message into a point $M$ on the curve. Choose random ephemeral integer $k$. Compute ciphertext pair:
    C1 = kG
    C2 = M + kQ
  3. Decryption: Using private key $d$, compute $dC_1 = kdG = kQ$. Recover message point by subtracting:
    M = C2 - dC1 = (M + kQ) - kQ

Role of the Keys

  • Private Key ($d$): Kept secret by the receiver. Essential for reversing encryption via scalar multiplication ($dC_1$) to eliminate the ephemeral masking factor.
  • Public Key ($Q$): Distributed openly. Used by senders to encrypt messages safely without ever exposing the private key.

2. The Caesar Cipher

The Caesar cipher is a monoalphabetic substitution cipher where every letter in the plaintext is shifted forward by a fixed integer key $k$ modulo 26.

  • Encryption: $E_k(x) = (x + k) \pmod{26}$
  • Decryption: $D_k(x) = (x - k) \pmod{26}$

3. Comparative Analysis

Contrasting asymmetric elliptic curve cryptography with the classical symmetric Caesar cipher:

Feature secp256k1 Toy Scheme Caesar Cipher
Type Asymmetric (Public-Key) Symmetric (Secret-Key / Substitution)
Mathematical Operations Algebraic point addition & scalar multiplication over finite fields. Simple modular integer arithmetic ($\pmod{26}$).
Key Space Extremely large ($\approx 2^{256}$), computationally secure against exhaustive search. Extremely small ($26$ possible keys), trivial brute-force search.
Statistical Properties High diffusion and pseudorandomness; ciphertext reveals zero information regarding plaintext letter distributions. Preserves single-letter frequency distributions entirely, rendering it vulnerable to statistical attacks.

4. Statistical Cryptanalysis of the Caesar Cipher

Given a sufficiently large corpus of text, we can automatically recover the unknown shift key without brute-forcing by analyzing letter frequencies. We apply the Chi-squared ($\chi^2$) statistic to evaluate how closely decrypted candidate text matches standard English letter distributions:

chi^2 = sum( (O_i - E_i)^2 / E_i )

Where $O_i$ represents the observed count of letter $i$ in the decrypted test candidate, and $E_i$ is the expected frequency count derived from standard English text statistics.
