3. Statistical & Theoretical Discussion

  • One-Way Function Property: Computing forward ($Q = kG$) via point addition and doubling is rapid, whereas reversing the calculation ($k$ from $Q$) is computationally unfeasible (ECDLP).
  • Periodicity & Distribution: In this finite field ($p = 17$), repeated additions generate a closed cyclic subgroup, showing how coordinates map across the curve space.
  • Avalanche Behavior: Unlike cryptographic hash functions (like Keccak) which are engineered for strict bit diffusion, elliptic curves maintain an algebraic group structure where neighboring points follow predictable geometric formulas.
