Exercise 1: Riemann vs. Lebesgue Integration

1. Conceptual Definitions

Riemann Integration (Domain Partitioning): Partition the domain [a, b] into N subintervals of length Δx_i. It evaluates sums based on function values sampled directly from these subintervals. It fails when functions oscillate wildly across subintervals.

Riemann Sum: S_N = Σ_{i=1}^{N} f(x_i*) · Δx_i

Lebesgue Integration (Range Partitioning): Partition the range [min f, max f] into measurable subsets E_j and determine the measure (length or size) of their preimages in the domain. This approach can integrate highly discontinuous and pathological functions.

Lebesgue Integral: ∫_E f dμ = Σ_j y_j* · μ( f⁻¹(E_j) )

2. Conceptual & Performance Comparison

Feature Riemann Integration Lebesgue Integration
Partition Strategy Domain [a, b] is divided into subintervals. Range [y_min, y_max] is divided into subsets.
Convergence Scope Requires continuity or bounded variation. Converges for all measurable functions.
Computational Aspect Fast and straightforward for continuous functions. Complex implementation due to preimage measure mapping.

3. Analysis of Pathological Functions

A. The Dirichlet Function

f(x) = 1 if x is rational, 0 if x is irrational on [0, 1]

  • Riemann Integration: Fails to converge. Any subinterval contains both rational and irrational numbers, yielding an upper sum of 1 and a lower sum of 0. Thus, it is not Riemann-integrable.
  • Lebesgue Integration: Rationals form a countable set of measure 0, while irrationals have measure 1. The integral evaluates to: (1 × 0) + (0 × 1) = 0.

B. Thomae's Function (Popcorn Function)

f(x) = 1/q if x = p/q in lowest terms, 0 if x is irrational on [0, 1]

  • Riemann & Lebesgue Integration: Both converge to 0 because points where f(x) > 0 form a countable set of measure zero.

Exercise 2: Numerical Computation of the Normal CDF

1. Mathematical Formulation

The standard normal cumulative distribution function (CDF) is defined by the integral:

Φ(x) = (1 / √(2π)) · ∫_{-∞}^{x} exp(-t² / 2) dt

2. Liouville's Theorem & Non-Elementary Integration

According to Liouville's Theorem in differential algebra, the antiderivative of exp(-t²) cannot be expressed as a finite combination of elementary functions (polynomials, exponentials, logarithms, or trigonometric functions). Therefore, no closed-form algebraic formula exists for Φ(x).

3. The Error Function (erf) as an Analytical Bridge

To establish an exact analytical formula, mathematics introduces the special Error Function:

erf(z) = (2 / √π) · ∫_{0}^{z} exp(-t²) dt

Using erf(z), the Normal CDF is represented analytically as:

Φ(x) = 0.5 · [ 1 + erf( x / √2 ) ]

Why numerical methods remain necessary: Evaluating erf(z) itself requires evaluating a non-elementary integral via numerical approximations or series expansions.

4. Numerical Implementation Strategies

  • Numerical Integration (Simpson's Rule): Truncate the infinite lower limit to -10 and apply Simpson's rule over N subintervals across [-10, x].
  • Power Series Expansion: Expand erf(z) into a Maclaurin series:
    erf(z) = (2 / √π) · Σ_{n=0}^{∞} [ (-1)^n · z^(2n+1) ] / [ n! · (2n+1) ]
    Summing terms until reaching a given threshold produces arbitrary precision.
